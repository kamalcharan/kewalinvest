1. Best and Worst Performer

What is it?

The dashboard identifies which market index performed the best (highest return) and worst (lowest return) during the selected time period.

How is it calculated?

Best Performer = MAX(return_value) across all indices
Worst Performer = MIN(return_value) across all indices
Where:
• return_value = The percentage return for the selected period (1M, 3M, 6M, or 1Y)
• The system fetches the latest calculated metrics for each index
• Indices without calculated metrics are excluded from comparison

Step-by-Step Process:

  1. Fetch all active market indices from the database
  2. For each index, get the latest record with calculated metrics
  3. Based on selected period (1M/3M/6M/1Y), extract the corresponding return field
  4. Compare all return values - highest becomes "Best Performer"
  5. Lowest becomes "Worst Performer" (derived from heatmap sorting)

2. Most Volatile

What is it?

Identifies the index with the highest price volatility (fluctuation) over the last 3 months. Higher volatility means larger price swings, indicating higher risk/reward potential.

How is it calculated?

Most Volatile = MAX(sd_3m) across all indices
Where:
• sd_3m = 3-month Standard Deviation of daily returns
• Standard Deviation measures how spread out the daily returns are from the mean

Standard Deviation Calculation:

SD = √(Σ(ri - r̄)² / n)
Where:
• ri = Daily return for day i
• r̄ = Mean (average) of all daily returns
• n = Number of trading days in the period
• Daily Return = ((Closetoday - Closeyesterday) / Closeyesterday) × 100

Step-by-Step Calculation

  1. Collect last 90 trading days of closing prices
  2. Calculate daily returns: ((today's close - yesterday's close) / yesterday's close) × 100
  3. Calculate the mean (average) of all daily returns
  4. For each daily return, calculate (return - mean)²
  5. Sum all squared differences and divide by count
  6. Take square root to get Standard Deviation

3. Index Performance Heatmap

What is it?

A visual grid showing all market indices with color-coded returns. Green shades indicate positive returns, red shades indicate negative returns. The intensity of color reflects the magnitude of return.

How is it generated?

Color Intensity = |return_value| / max_absolute_return
Logic:
• return_value > 0 → Green shades (positive performance)
• return_value < 0 → Red shades (negative performance)
• return_value = 0 or null → Neutral/Gray
• Darker shade = Higher magnitude of return

4. Index Returns (1M, 3M, 6M, 1Y, YTD, All)

What is it?

Percentage change in the index value over different time periods. Shows how much an investment would have gained or lost if held for that duration.

Return Calculation Formula

Return % = ((End Price - Start Price) / Start Price) × 100
Example:
If NIFTY 50 was at ₹18,000 one month ago and is now at ₹18,540:
Return = ((18,540 - 18,000) / 18,000) × 100 = +3.00%

5. Volatility (7D, 14D, 30D, 60D, 90D)

What is it?

Measures the degree of variation in the index's daily returns over different time windows. Higher volatility indicates greater price fluctuations and risk.

Volatility Windows

Period Field Name Trading Days Use Case
7-Day sd_7d ~5 trading days Very short-term volatility
14-Day sd_14d ~10 trading days Short-term trend volatility
21-Day (30D) sd_21d ~15 trading days Monthly volatility (approx 1 month)
42-Day (60D) sd_42d ~30 trading days Bi-monthly volatility
3-Month (90D) sd_3m ~63 trading days Quarterly volatility
6-Month sd_6m ~126 trading days Semi-annual volatility

Volatility Calculation Process

function calculateStandardDeviation(prices) { // Step 1: Calculate daily returns const returns = []; for (let i = 1; i < prices.length; i++) { const ret = ((prices[i] - prices[i-1]) / prices[i-1]) * 100; returns.push(ret); } // Step 2: Calculate mean of returns const mean = returns.reduce((a, b) => a + b, 0) / returns.length; // Step 3: Calculate variance const variance = returns.reduce((sq, n) => sq + Math.pow(n - mean, 2), 0) / returns.length; // Step 4: Return standard deviation return Math.sqrt(variance); }

Volatility Comparison Chart

Interpreting Volatility:
  • < 1% - Low volatility (stable, defensive stocks)
  • 1% - 2% - Moderate volatility (typical market conditions)
  • 2% - 3% - High volatility (growth stocks, small caps)
  • > 3% - Very high volatility (speculative, high risk)

6. Key Metrics (CAGR, Sharpe, Max DD, Risk)

6.1 CAGR (Compound Annual Growth Rate)

CAGR = (End Value / Start Value)(1/Years) - 1
What it tells you: The smoothed annual rate at which an investment would have grown if it had grown at a steady rate. Useful for comparing investments over different time periods.
Example Calculation:

If NIFTY 50 was at ₹15,000 five years ago and is now at ₹24,500:

CAGR = (24500 / 15000)(1/5) - 1 = 1.6330.2 - 1 = 10.31%

This means the index grew at an average rate of 10.31% per year over 5 years.

6.2 Sharpe Ratio

Sharpe Ratio = (Return - Risk-Free Rate) / Standard Deviation
What it tells you: How much excess return you receive for the extra volatility you endure. Higher Sharpe ratio = better risk-adjusted returns.

Risk-Free Rate: Default is 6.5% (configurable via RISK_FREE_RATE env variable)
Sharpe Ratio Interpretation
< 1.0 Poor risk-adjusted returns
1.0 - 2.0 Good risk-adjusted returns
> 2.0 Excellent risk-adjusted returns
Example:

1-Month Return = 3.00%, 30-Day Volatility = 1.20%, Risk-Free Rate = 6.5% (annualized, ~0.54% monthly)

Sharpe = (3.00 - 0.54) / 1.20 = 2.05

6.3 Maximum Drawdown (Max DD)

Max Drawdown = ((Trough - Peak) / Peak) × 100
What it tells you: The largest peak-to-trough decline in the index value. Shows the worst-case scenario an investor would have experienced.

The system calculates this over the last 252 trading days (~1 year).
Example:

If the index peaked at ₹25,000 and then fell to ₹21,250 before recovering:

Max Drawdown = ((21250 - 25000) / 25000) × 100 = -15.00%

6.4 Total Risk

Total Risk = 30-Day Standard Deviation (sd_30d)
What it tells you: A proxy for total portfolio risk, using the 30-day volatility as the measure. Higher values indicate higher risk.
