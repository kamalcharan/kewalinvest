1. Best and Worst Performer

What is it?

The dashboard identifies which market index performed the best (highest return) and worst (lowest return) during the selected time period.

How is it calculated?

Best Performer = MAX(return_value) across all indices
Worst Performer = MIN(return_value) across all indices
Where:
• return_value = The percentage return for the selected period (1M, 3M, 6M, or 1Y)
• The system fetches the latest calculated metrics for each index
• Indices without calculated metrics are excluded from comparison

Step-by-Step Process:

  1. Fetch all active market indices from the database
  2. For each index, get the latest record with calculated metrics
  3. Based on selected period (1M/3M/6M/1Y), extract the corresponding return field
  4. Compare all return values - highest becomes "Best Performer"
  5. Lowest becomes "Worst Performer" (derived from heatmap sorting)

2. Most Volatile

What is it?

Identifies the index with the highest price volatility (fluctuation) over the last 3 months. Higher volatility means larger price swings, indicating higher risk/reward potential.

How is it calculated?

Most Volatile = MAX(sd_3m) across all indices
Where:
• sd_3m = 3-month Standard Deviation of daily returns
• Standard Deviation measures how spread out the daily returns are from the mean

Standard Deviation Calculation:

SD = √(Σ(ri - r̄)² / n)
Where:
• ri = Daily return for day i
• r̄ = Mean (average) of all daily returns
• n = Number of trading days in the period
• Daily Return = ((Closetoday - Closeyesterday) / Closeyesterday) × 100

Step-by-Step Calculation

  1. Collect last 90 trading days of closing prices
  2. Calculate daily returns: ((today's close - yesterday's close) / yesterday's close) × 100
  3. Calculate the mean (average) of all daily returns
  4. For each daily return, calculate (return - mean)²
  5. Sum all squared differences and divide by count
  6. Take square root to get Standard Deviation

4. Index Returns (1M, 3M, 6M, 1Y, YTD, All)

What is it?

Percentage change in the index value over different time periods. Shows how much an investment would have gained or lost if held for that duration.

Return Calculation Formula

Return % = ((End Price - Start Price) / Start Price) × 100
Example:
If NIFTY 50 was at ₹18,000 one month ago and is now at ₹18,540:
Return = ((18,540 - 18,000) / 18,000) × 100 = +3.00%

5. Volatility (7D, 14D, 30D, 60D, 90D)

What is it?

Measures the degree of variation in the index's daily returns over different time windows. Higher volatility indicates greater price fluctuations and risk.

Volatility Windows

Period Field Name Trading Days Use Case
7-Day sd_7d ~5 trading days Very short-term volatility
14-Day sd_14d ~10 trading days Short-term trend volatility
21-Day (30D) sd_21d ~15 trading days Monthly volatility (approx 1 month)
42-Day (60D) sd_42d ~30 trading days Bi-monthly volatility
3-Month (90D) sd_3m ~63 trading days Quarterly volatility
6-Month sd_6m ~126 trading days Semi-annual volatility

Volatility Calculation Process

function calculateStandardDeviation(prices) { // Step 1: Calculate daily returns const returns = []; for (let i = 1; i < prices.length; i++) { const ret = ((prices[i] - prices[i-1]) / prices[i-1]) * 100; returns.push(ret); } // Step 2: Calculate mean of returns const mean = returns.reduce((a, b) => a + b, 0) / returns.length; // Step 3: Calculate variance const variance = returns.reduce((sq, n) => sq + Math.pow(n - mean, 2), 0) / returns.length; // Step 4: Return standard deviation return Math.sqrt(variance); }

Volatility Comparison Chart

Interpreting Volatility:
  • < 1% - Low volatility (stable, defensive stocks)
  • 1% - 2% - Moderate volatility (typical market conditions)
  • 2% - 3% - High volatility (growth stocks, small caps)
  • > 3% - Very high volatility (speculative, high risk)

6. Key Metrics (CAGR, Sharpe, Max DD, Risk)

6.1 CAGR (Compound Annual Growth Rate)

CAGR = (End Value / Start Value)(1/Years) - 1
What it tells you: The smoothed annual rate at which an investment would have grown if it had grown at a steady rate. Useful for comparing investments over different time periods.
Example Calculation:

If NIFTY 50 was at ₹15,000 five years ago and is now at ₹24,500:

CAGR = (24500 / 15000)(1/5) - 1 = 1.6330.2 - 1 = 10.31%

This means the index grew at an average rate of 10.31% per year over 5 years.

6.2 Sharpe Ratio

Sharpe Ratio = (Return - Risk-Free Rate) / Standard Deviation
What it tells you: How much excess return you receive for the extra volatility you endure. Higher Sharpe ratio = better risk-adjusted returns.

Risk-Free Rate: Default is 6.5% (configurable via RISK_FREE_RATE env variable)
Sharpe Ratio Interpretation
< 1.0 Poor risk-adjusted returns
1.0 - 2.0 Good risk-adjusted returns
> 2.0 Excellent risk-adjusted returns
Example:

1-Month Return = 3.00%, 30-Day Volatility = 1.20%, Risk-Free Rate = 6.5% (annualized, ~0.54% monthly)

Sharpe = (3.00 - 0.54) / 1.20 = 2.05

6.3 Maximum Drawdown (Max DD)

Max Drawdown = ((Trough - Peak) / Peak) × 100
What it tells you: The largest peak-to-trough decline in the index value. Shows the worst-case scenario an investor would have experienced.

The system calculates this over the last 252 trading days (~1 year).
Example:

If the index peaked at ₹25,000 and then fell to ₹21,250 before recovering:

Max Drawdown = ((21250 - 25000) / 25000) × 100 = -15.00%

6.4 Total Risk

Total Risk = 30-Day Standard Deviation (sd_30d)
What it tells you: A proxy for total portfolio risk, using the 30-day volatility as the measure. Higher values indicate higher risk.

1. Overview & Key Differences

What is NAV Tracking?

NAV (Net Asset Value) Tracking analyzes mutual fund performance using the same calculation engine as Index Analysis. The key difference is the data source - mutual funds have a single NAV value per day instead of OHLC (Open, High, Low, Close) data.

Important: NAV Tracking uses the same calculation formulas as Index Analysis. The underlying marketMetricsCalculator.service.ts powers both modules.

Index Analysis vs NAV Tracking

Aspect Index Analysis NAV Tracking
Data Source Market Indices (NIFTY 50, NIFTY IT, Bank NIFTY) Mutual Fund Schemes (HDFC Equity, ICICI Bluechip)
Price Data OHLC (Open, High, Low, Close) + Volume Single NAV value per day
Database Table t_market_data t_nav_data
Calculation Service marketMetricsCalculator.service.ts schemeMetricsCalculator.service.ts → calls marketMetricsCalculator
Metrics Calculated Same metrics for both: Returns, Volatility, CAGR, Sharpe Ratio, Max Drawdown, Total Risk

1. Networth Projection

Overview

The Networth Projection chart displays historical portfolio values and projects future growth based on an assumed annual growth rate. This is the primary visualization on the Customer Dashboard.

Key Features:
  • Historical data displayed as solid line (green for growth, red for decline)
  • Projected data displayed as dashed line
  • Supports timeframes: 1M, 3M, 6M, 1Y, 24M
  • Adjustable growth rate assumption (4% - 30%)
  • Filter by asset type (MF, FD, Gold, etc.)
  • Handles planned withdrawals in projection

Monthly Growth Rate Calculation

Annual growth rate is converted to monthly compounding rate:

Monthly Growth Rate = (1 + Annual Rate / 100)1/12 - 1
Example: 8% Annual Growth Rate
Parameter Calculation Result
Annual Rate Given 8%
Monthly Rate (1 + 0.08)^(1/12) - 1 0.6434%
Verification (1.006434)^12 ≈ 1.08 (8%)

Projection Calculation Formula

Each month's projected value is calculated as:

Next Month Value = Current Value × (1 + Monthly Growth Rate) + Monthly Contribution
12-Month Projection Example

Starting Value: ₹10,00,000 | Annual Rate: 8% | Monthly Contribution: ₹25,000

Month Opening Value Growth (0.6434%) + Contribution Closing Value
Month 1 ₹10,00,000 ₹6,434 ₹25,000 ₹10,31,434
Month 2 ₹10,31,434 ₹6,636 ₹25,000 ₹10,63,070
Month 3 ₹10,63,070 ₹6,840 ₹25,000 ₹10,94,910
... Continues for projection period
Month 12 ₹13,52,890 ₹8,705 ₹25,000 ₹13,86,595

Withdrawal Impact on Projection

When scheduled withdrawals exist, they are subtracted from the projected value:

Post-Withdrawal Value = Projected Value - Withdrawal Amount
Withdrawal Handling:
  • Withdrawals are matched by month (YYYY-MM format)
  • Multiple withdrawals in same month are summed
  • Value cannot go below zero: Math.max(0, currentValue)
  • Withdrawal points shown with red inverted triangle marker

Projected Growth Percentage

Projected Growth % = ((Projected Value - Current Value) / Current Value) × 100
Example Calculation
  • Current Networth: ₹25,00,000
  • Projected (12M @ 8%): ₹27,07,847
  • Growth: ((27,07,847 - 25,00,000) / 25,00,000) × 100 = +8.31%

2. Portfolio Performance (Month-over-Month)

Overview

Portfolio Performance calculates Month-over-Month (MoM) changes to show how a portfolio grew or declined. The system calculates two types of MoM to provide accurate performance insights.

Why Two MoM Types?
When a customer adds new investments mid-month, the simple value-based MoM can be misleading. Example:
  • Previous month: ₹10,00,000
  • New investment: ₹5,00,000
  • Current month: ₹15,50,000
  • Simple MoM shows +55% (misleading!)
  • Returns-based MoM shows +3.33% (actual market growth)

Type 1: Value-Based MoM (Traditional)

Measures total portfolio value change including new investments:

MoM Change % = ((Current Value - Previous Value) / Previous Value) × 100
Value-Based MoM Example
Month Portfolio Value MoM Change MoM %
October 2024 ₹10,00,000 - -
November 2024 ₹10,35,000 ₹35,000 +3.50%
December 2024 ₹10,15,000 -₹20,000 -1.93%

Type 2: Returns-Based MoM (True Performance)

Measures actual market returns, excluding the impact of new investments:

Returns MoM % = ((Current Returns - Previous Returns) / Previous Value) × 100

Where:

  • Returns = Current Value - Total Invested
  • Returns Change = Current Returns - Previous Returns
Returns-Based MoM Example
Month Value Invested Returns Returns MoM
October ₹10,00,000 ₹8,00,000 ₹2,00,000 -
November ₹15,50,000 ₹13,00,000 ₹2,50,000 +5.00%
Calculation:
Returns Change = ₹2,50,000 - ₹2,00,000 = ₹50,000
Returns MoM = (₹50,000 / ₹10,00,000) × 100 = +5.00%
(Note: ₹5,00,000 new investment had no impact on this calculation)

Significant Investment Detection

The system flags months where new investments exceed 10% of previous portfolio value:

Is Significant = |Investment Change| > (Previous Value × 0.10)
Significance Detection
Previous Value New Investment Threshold (10%) Is Significant?
₹10,00,000 ₹50,000 ₹1,00,000 No
₹10,00,000 ₹2,00,000 ₹1,00,000 Yes ⚠️

MoM Calculation Output

The calculatePortfolioMoM() function returns:

Field Type Description

mom_change_absolute number Absolute value change (₹)
returns_mom_percentage number Returns-based MoM %

Cumulative Returns Calculation

Unlike MoM which measures point-to-point monthly changes, Cumulative Returns track total growth from a starting point to current date.

Cumulative Return % = ((Current Value - Initial Investment) / Initial Investment) × 100
Alternatively with multiple investments:
Cumulative Return % = ((Current Value - Total Invested) / Total Invested) × 100

MoM vs Cumulative - Key Difference

Aspect MoM (Month-over-Month) Cumulative
Measures Change between consecutive months Total growth from inception
Reference Point Previous month's value Initial investment (Day 0)

1. Investment Plan Current Value Calculation

Overview

Investment plans can be of different types: One-time (lump sum), SIP (Systematic Investment Plan), or Recurring. Each type has a different formula for calculating the current value.

Supported Asset Types:
  • FD (Fixed Deposit) - Default rate: 6-7%
  • Gold - Default rate: 4-6%
  • Real Estate - Default rate: 5-7%
  • Mutual Funds (MF) - Default rate: 10-14%
  • PPF - Default rate: 7.1%
  • NPS - Default rate: 10-12%
  • Bonds - Default rate: 7-8%

One-Time Investment (Lump Sum)

Uses compound interest formula:

FV = PV × (1 + r)t
Where:
• FV = Future Value (Current Value after t years)
• PV = Principal Amount (Initial Investment)
• r = Annual Growth Rate (assumption_rate / 100)
• t = Years Elapsed since start_date
One-Time Investment Example
Parameter Value
Asset Type Fixed Deposit (FD)
Principal Amount (PV) ₹5,00,000
Start Date Nov 28, 2023
Assumption Rate (r) 7.0% p.a.
Years Elapsed (t) 2 years
Current Value (FV) ₹5,00,000 × (1.07)² = ₹5,72,450

SIP / Recurring Investment

Combines lump sum growth with future value of annuity:

FV = PV × (1 + r)t + PMT × [((1 + rp)n - 1) / rp] × (1 + rp)
Where:
• PV = Initial Principal Amount
• PMT = Recurring Payment (monthly/quarterly/yearly)
• r = Annual Growth Rate
• rp = Periodic Rate (annual / payments per year)
• n = Total Number of Payments Made
• t = Years Elapsed

Assumption Rate 12% p.a.
Duration 3 years (36 payments)
Periodic Rate (rp) 12% / 12 = 1% per month
Principal FV ₹1,00,000 × (1.12)³ = ₹1,40,493
SIP FV ₹10,000 × [((1.01)³⁶ - 1) / 0.01] × 1.01 = ₹4,35,077
Total Current Value ₹1,40,493 + ₹4,35,077 = ₹5,75,570

7. Monte Carlo Success Probability

Overview

Monte Carlo simulation runs 1000 scenarios with randomized returns to estimate the probability of reaching a goal target.

Success Probability = (Successful Simulations / Total Simulations) × 100
Simulation Parameters:
• simulations = 1000 (default)
• volatility = 15% standard deviation (default)
• Each month applies a random return from normal distribution

Simulation Process

  1. Initialize corpus with current portfolio value
  2. For each month until target date, apply random monthly return
  3. Random return uses normal distribution: mean = expected return/12, stdDev = volatility/√12
  4. Add monthly SIP contribution after applying return
  5. Check if final corpus ≥ target amount
  6. Repeat 1000 times and count successes

Confidence Level Classification

Probability Confidence Level Interpretation
≥ 90% Very High Goal is highly likely to be achieved
75% - 89% High Goal is on track
60% - 74% Medium Consider increasing SIP
40% - 59% Low Action required - increase SIP or extend timeline
< 40% Very Low Goal unlikely without significant changes
Important Note:
Monte Carlo uses the Box-Muller transform for generating normally distributed random numbers, simulating real-world market volatility where returns aren't constant.

2. Goal Health Calculation

Overview

Goal health is determined by combining two key metrics: On-Track Status and Success Probability.

On-Track Status Formula

On Track = (projected_corpus ≥ target_amount) AND (probability ≥ 75%)
A goal is considered "on track" only when BOTH conditions are met:
• Projected corpus meets or exceeds the target
• Monte Carlo probability is at least 75%

Deviation Percentage

Deviation % = ((projected_corpus - target_amount) / target_amount) × 100
Interpretation:
• Positive: Projected to exceed target
• Negative: Shortfall expected
• ±5% is considered acceptable variance

Progress Percentage

Progress % = MIN(100, (current_value / target_amount) × 100)
Shows how much of the target has been accumulated so far. Capped at 100% even if current value exceeds target.

6. Goal Status Classification

Portfolio Value for Goals

Each goal's current value is calculated from linked scheme allocations:

Goal Value = Σ (Scheme Units × NAV × Allocation %)
Example:

Allocation = 60%
Goal Value Contribution = ₹1,22,750 × 0.60 = ₹73,650

Status Determination Flow

  1. Calculate current portfolio value from linked investments
  2. Project future value using expected return rate
  3. Run Monte Carlo simulation (1000 iterations)
  4. Determine on_track status (projected ≥ target AND probability ≥ 75%)
  5. Classify confidence level (very_high to very_low)
  6. Generate recommendations based on gaps
