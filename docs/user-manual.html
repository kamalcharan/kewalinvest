KewalInvest User Manual

Welcome to KewalInvest, a comprehensive financial portfolio management system designed for wealth managers, financial advisors, and investment professionals. This manual will guide you through all features and functionalities of the application.

ℹ️ About This Manual
This user manual covers all features available in KewalInvest. Features marked with Admin require administrator privileges.

Key Capabilities

Multi-Asset Portfolio

Track 9 different asset types including MF, Equity, Gold, FD, PPF, EPF, NPS, Real Estate & Insurance

Goal-Based Planning

Create and track financial goals with smart investment allocation and progress monitoring

Customer Management

Complete customer lifecycle from contact to portfolio with family relationship tracking

Market Intelligence

Real-time NAV tracking, market index analysis, and performance benchmarking

Data Import

Bulk import customers, transactions, and market data via CSV/Excel files

Alerts & Monitoring

Cruise Control dashboard for portfolio alerts and automated monitoring

Getting Started

Logging In

To access KewalInvest, navigate to your organization's application URL and enter your credentials:

  1. Enter your email address - Use the email provided by your administrator
  2. Enter your password - Passwords are case-sensitive
  3. Click "Sign In" - You will be redirected to the dashboard
⚠️ Security Note
Never share your login credentials. If you suspect unauthorized access, contact your administrator immediately.

Contact Management

Contacts are the foundation of customer relationships in KewalInvest. Every customer starts as a contact before being onboarded as a full customer.

Creating a Contact

  1. Navigate to Contacts - Click "Contacts" in the sidebar under the Contacts section
  2. Click "Add Contact" - Opens the contact creation form
  3. Fill in basic information - Name, primary email, phone number
  4. Add communication channels - Additional emails, phone numbers, social media
  5. Save the contact - Click "Create Contact" to save

Contact Fields

Field Required Description
First Name Yes Contact's first name
Last Name Yes Contact's last name
Email Yes Primary email address
Phone No Primary phone number
Notes No Additional information about the contact

Communication Channels

Each contact can have multiple communication channels. Set one channel as primary for default communications.

💡 Tip
Mark the most frequently used contact method as "Primary" to ensure important communications reach the contact efficiently.

Family Relationships

Track family relationships to understand household finances and enable family-level reporting:

  1. Open customer profile - Navigate to the customer's detail page
  2. Go to Family tab - Click on the "Family" tab
  3. Add relationship - Click "Add Family Member"
  4. Select relationship type - Choose from: Spouse, Child, Parent, Sibling, etc.
  5. Link to existing customer - Search and select an existing customer or create new
ℹ️ Note
Family relationships are bidirectional. When you link Customer A as the spouse of Customer B, the reverse relationship is automatically created.

Customer Bookmarks

Bookmark customers for quick access or to flag them for follow-up:

  • Click the bookmark icon on any customer card or profile
  • Add a reason for bookmarking (e.g., "Pending KYC", "Review portfolio")
  • View all bookmarked customers from the Bookmarks filter

Investment Plans

Investment plans represent systematic or lump-sum investment commitments:

Creating an Investment Plan

  1. Go to customer portfolio - Open the customer's detail page and navigate to Portfolio tab
  2. Click "Add Investment Plan" - Opens the investment plan form
  3. Select asset type - Choose from the 9 supported asset types
  4. Enter investment details - Amount, frequency (SIP/Lump-sum), start date
  5. Configure tracking - Link to specific scheme (for MF) or add custom details
  6. Save the plan - The plan appears in the customer's portfolio

Investment Plan Types

Type Description Use Case

Lump Sum One-time investment Single large investments
STP Systematic Transfer Plan Periodic transfers between funds

Portfolio Snapshots

Portfolio snapshots capture the state of a customer's portfolio at a specific point in time, enabling historical analysis and networth tracking.

Automatic Snapshots

The system automatically creates monthly portfolio snapshots on the last day of each month, capturing:

  • Total portfolio value
  • Asset allocation breakdown
  • Individual holding values
  • Performance metrics

Manual Snapshots

Administrators can trigger manual snapshots from the Cruise Control dashboard:

  1. Navigate to Cruise Control in the sidebar
  2. Go to the Snapshots tab
  3. Click "Trigger Snapshot"
  4. Confirm the action

Networth Projections

Based on historical snapshots and growth rates, the system projects future networth:

  • View projected growth over 1, 3, 5, 10 years
  • Compare actual vs. projected performance
  • Identify trends and anomalies

Goals Management

Goal-based financial planning is at the heart of KewalInvest. Create financial goals for customers and track progress with smart investment allocation.

Goal Types

KewalInvest supports three types of financial goals:

Time-Based Goals

Goals with a target date but flexible target amount. Example: "Retirement by age 60"

Price-Based Goals

Goals with a target amount but flexible timeline. Example: "Save ₹50 lakhs"

Time + Price Goals

Goals with both target date and amount. Example: "₹1 Crore for child's education by 2030"

Creating a Goal

  1. Navigate to customer profile - Open the customer's detail page
  2. Go to Goals tab - Click on the "Goals" tab
  3. Click "Add Goal" - Opens the goal creation wizard
  4. Enter goal details - Name, type, target amount, target date
  5. Set priority - High, Medium, or Low priority
  6. Save the goal - Goal appears in the goals list

Goal Configuration

Field Description Example
Goal Name Descriptive name for the goal "Child's Higher Education"
Target Amount Desired amount to achieve ₹50,00,000
Target Date When the goal should be achieved March 2030
Priority Importance level High
Notes Additional context or requirements "Include inflation adjustment"

Investment Allocation

Link investment plans to goals to track dedicated progress:

  1. Open goal details - Click on a goal to view details
  2. Click "Allocate Investments" - Opens the allocation modal
  3. Select investment plans - Choose from customer's existing investment plans
  4. Set allocation percentage - Specify what percentage of each plan goes to this goal
  5. Save allocations - System calculates goal progress based on allocations
💡 Smart Allocation
The system suggests optimal allocations based on goal timeline, risk profile, and asset type suitability. Review suggestions but customize as needed.

Allocation Rules

  • Each investment plan can be allocated across multiple goals
  • Total allocation per plan cannot exceed 100%
  • Unallocated portions are tracked separately
  • Changes to allocations immediately update goal progress

Progress Tracking

Monitor goal progress with real-time calculations:

Progress Metrics

Metric Description
Current Value Current value of all investments allocated to the goal
Progress % Percentage of target amount achieved
Projected Value Estimated value at target date based on growth rate
Status On-track or Off-track indicator
Shortfall/Surplus Difference between projected and target amounts
Monthly SIP Required Additional monthly investment needed to get on track

Risk Levels

Goals are assigned risk levels based on asset allocation:

  • Low Risk - Primarily debt instruments (FD, PPF, EPF)
  • Medium Risk - Balanced allocation (Hybrid funds, mix of equity/debt)
  • High Risk - Primarily equity (MF equity, direct stocks)

Goal Status Indicators

Understanding Goal Status
On Track Projected value meets or exceeds target amount by target date
Off Track Projected value falls short of target - action recommended
Achieved Goal has been successfully completed

Transaction Management

Track all investment transactions including purchases, sales, dividends, and switches.

Transaction Types

Type Description Impact
Buy/Purchase New investment or additional purchase Increases holdings
Sell/Redemption Partial or full redemption Decreases holdings
Switch In Units received from another scheme Increases holdings
Switch Out Units transferred to another scheme Decreases holdings
Dividend Dividend payout or reinvestment May increase holdings (reinvestment)

Recording Transactions

  1. Navigate to Transactions - Click "Transactions" in the sidebar
  2. Click "Add Transaction" - Opens the transaction form
  3. Select customer - Search and select the customer
  4. Choose transaction type - Buy, Sell, Switch, etc.
  5. Enter details - Amount, units, NAV, date
  6. Save transaction - Transaction is recorded and portfolio updated

Duplicate Detection

The system automatically detects potential duplicate transactions during data import:

⚠️ Duplicate Review
When duplicates are detected, review them in the Duplicate Review Panel before confirming. You can merge duplicates or mark them as separate transactions.

Using the Duplicate Review Panel

  1. Go to Transactions page - Navigate to the transactions list
  2. Click "Review Duplicates" - Opens the duplicate review panel
  3. Review each group - System shows transactions that appear similar
  4. Take action - Keep all, merge, or delete duplicates
  5. Confirm changes - Apply your decisions

Import Wizard

The multi-step import wizard guides you through the data import process:

1. Upload File → 2. Select Type → 3. Map Fields → 4. Validate → 5. Import

Step 1: Upload File

  1. Navigate to Data Import - Click "Import Data" in the sidebar
  2. Select file - Click "Choose File" or drag and drop
  3. Verify preview - Check that data appears correctly

Step 2: Select Import Type

Choose what type of data you're importing. The system will adjust field mappings accordingly.

Step 3: Field Mapping

Map columns from your file to database fields:

  • System auto-detects common field names
  • Review and adjust mappings as needed
  • Required fields must be mapped
  • Unmapped columns are ignored
💡 Tip
Save field mappings as templates for recurring imports with the same file format.

Step 4: Validation

The system validates your data before import:

  • Required field checks
  • Data type validation
  • Duplicate detection
  • Reference integrity (e.g., valid scheme codes)

Step 5: Execute Import

Review the validation summary and execute the import:

  • View records to be imported
  • Review warnings and errors
  • Click "Import" to proceed
  • Monitor progress in real-time

Import Dashboard

Monitor all import sessions from the Import Dashboard:

  • View active and completed imports
  • Check success/failure counts
  • Download error logs
  • Rollback failed imports (if supported)
⚠️ Important
Always backup your data before performing large imports. Some import operations cannot be undone.

Frequently Asked Questions

General Questions

How do I reset my password?

Click "Forgot Password" on the login page and enter your email. You'll receive a password reset link. If you don't receive the email, contact your administrator.

Can I access KewalInvest on mobile?

Yes, KewalInvest is responsive and works on mobile browsers. For the best experience, we recommend using a tablet or desktop.

How often is NAV data updated?

NAV data can be updated daily via the NAV Scheduler or manually through the NAV History page. The frequency depends on your organization's configuration.

Portfolio Questions

Why is my portfolio value different from my broker statement?

Differences may occur due to: (1) NAV data timing differences, (2) Pending transactions not yet recorded, (3) Different valuation methods. Ensure all transactions are imported and NAV data is current.

How are goal progress calculations made?

Goal progress is calculated based on current values of allocated investments, projected growth rates, and target amounts. The system uses historical returns and expected growth to project future values.

Can I track assets not held through you?

Yes, you can manually add any asset type including real estate, insurance, and direct equity holdings. These will be included in the customer's total portfolio view.

Data Import Questions

What file formats are supported for import?

KewalInvest supports CSV and Excel (.xlsx) formats. Ensure your file has headers in the first row and data starts from the second row.

How do I handle import errors?

After import, check the Import Dashboard for error details. Common issues include: missing required fields, invalid data formats, and duplicate records. Fix the source file and re-import.

Can I undo an import?

Some imports support rollback. Check the Import Dashboard for the rollback option. For safety, always backup data before large imports.
